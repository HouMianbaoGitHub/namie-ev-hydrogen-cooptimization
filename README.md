# Namie Town EV–hydrogen model

Code, inputs and results for *Electric-Vehicle Flexibility and Hydrogen Storage in Renewable Capacity Planning for an
Export-Oriented Municipality* (Tuo Zhang and Takuro Kobashi, Tohoku University).

Everything is in [`pypsa_energies_revision/`](pypsa_energies_revision/); see its README.
