## 3 时间约定

- 全部为 JST。日本不实行夏令时，所以没有重复或缺失的小时，各年按 8,760／8,784 h 计。
- **时间戳 = 小时起点（hour-beginning）**：`2024-04-01 00:00` 表示 00:00–01:00。
  - JEPX：時刻コード k（1–48）对应 `(k−1)×30 min` 起点的 30 分时段。每小时取两个时段的简单平均价，約定量为两段之和。
  - 30 分格式 eria_jukyu：`TIME=0:00` 即 0:00–0:30 时段（MW 平均）。每小时取两段平均。
  - 旧 1 小时格式（TEPCO area-YYYY、东北 juyo_*Q）：`0:00` 即 0:00–1:00 的电量。
- FY = 4 月至次年 3 月，列 `fy`。

## 4 单位换算

| 原始文件 | 原始单位 | 换算 |
|---|---|---|
| TEPCO area-YYYY.csv（至 2024-01） | 万kWh／小时 | ×10 → MWh/h = MW 平均 |
| 东北 juyo_YYYY_tohoku_nQ.csv（至 2024-01） | MWh／小时 | 直接作为 MW 平均 |
| eria_jukyu_YYYYMM_02/03.csv（2024-02 起） | MW 平均（30 分） | 两段平均 → 小时 MW 平均 |
| JEPX 价格 | 円/kWh | 小时内两段简单平均（未按量加权） |
| JEPX 約定総量 | kWh／30 分 | 求和 ÷1000 → `jepx_volume_mwh`（MWh/h） |

新旧格式在 2024-02-01 00:00 切换。两家公司的旧文件都在 2024-01-31 结束，月度新文件从 2024-02 开始。

## 5 列定义（processed/hourly_tohoku_tokyo.parquet）

索引 `ts_jst_hour_beginning`。除价格（円/kWh）和 `jepx_volume_mwh` 外，均为 **MW（小时平均）**。

| 列 | 日文原表头（新格式／旧格式） | 说明 |
|---|---|---|
| price_system | システムプライス(円/kWh) | |
| price_tohoku / price_tokyo / price_hokkaido | エリアプライス東北／東京／北海道(円/kWh) | |
| jepx_volume_mwh | 約定総量(kWh) | 全国約定量 |
| split_slots | — | 该小时内东北≠东京的 30 分时段数（0–2） |
| *_demand | エリア需要 | |
| *_nuclear | 原子力 | |
| *_thermal | 火力(LNG)+火力(石炭)+火力(石油)+火力(その他)／火力 | 不含"火力出力制御量" |
| *_hydro | 水力 | 不含揚水 |
| *_geothermal, *_biomass | 地熱, バイオマス | |
| *_solar | 太陽光発電実績／太陽光実績 | 实际出力（已扣除出力制御） |
| *_solar_curtail | 太陽光出力制御量／太陽光抑制量 | |
| *_wind, *_wind_curtail | 風力発電実績, 風力出力制御量／風力実績, 風力抑制量 | |
| *_pumped | 揚水 | 正 = 发电，负 = 抽水 |
| *_battery | 蓄電池 | 仅 2024-02 起有；之前为 NaN |
| *_interconnector | 連系線 | **正 = 净受电（输入本区域），负 = 净送电（输出）**。这是该区域**所有**连系线的净合计：东北 = 东北东京间 + 北海道本州间 HVDC；东京 = 东北东京间 + 东京中部间 FC 等。它不等于单条东北东京间线路的潮流 |

东北新格式中的"その他""火力出力制御量""バイオマス出力制御量"未进入主表（量很小）。供需平衡检验：在不计"その他"时，东北 |供给合计−需要| 中位数 3 MW、p99 26 MW；东京中位数 0 MW、p99 389 MW。

残余负荷可按需自行构造，例如 `tohoku_demand − tohoku_solar − tohoku_wind`，以及"含出力制御的可用量"版本。

## 8 注意事项

- 价格为两段简单平均。如需负荷加权，可以从 raw/ 重新计算。
- 2024-02 前后数据粒度不同：旧格式为 1 小时整数电量，新格式为 30 分 MW 平均。旧格式整数取整到 MWh（东北）或 10 MWh（东京，万kWh 精度）。
- 连系线变量是区域净交换，不是东北东京间单线潮流（见第 5 节）。
- 东京 FY2026 的出力制御（太阳光 0.22 TWh）是东京区域首次大规模实施，FY2025 中已有少量。
